# Портфолио — ФИИТ, РТУ МИРЭА

Одностраничный сайт-портфолио студента направления 02.03.02 «Фундаментальная информатика и информационные технологии», профиль «Искусственный интеллект и машинное обучение».

Без сборки и зависимостей: три файла, которые браузер открывает как есть.

## Что внутри

```
index.html    разметка всех секций
config.js     имя, город, контакты, список нейросетей — правится в первую очередь
styles.css    токены тем, сетки, адаптив, анимации
script.js     конфиг, темы, вкладки плана, меню, попапы нейросетей, появление блоков
logos/        логотипы нейросетей для ленты
.nojekyll     чтобы GitHub Pages не пропускал файлы через Jekyll
.github/workflows/deploy.yml   автодеплой на Pages при push в main
```

## Свой конфиг

Личные данные вынесены в `config.js` — один объект `window.SITE_CONFIG`:

```js
window.SITE_CONFIG = {
  name: { first: 'Алексей', last: 'Гальченко' },
  city: 'Москва',
  contacts: {
    email: 'you@example.com',
    telegram: 'ваш_логин',      // без @ и без ссылки
    github: 'ваш-логин',        // только логин
    resume: 'cv.pdf'
  },
  share: { url: 'https://ваш-сайт/', text: 'Текст для кнопок «поделиться»' },
  ai: { /* карточки нейросетей: name, maker, about, uses, rating */ }
};
```

Скрипт сам подставит имя в заголовок, вкладку браузера и подвал, соберёт ссылки
`mailto:`, `t.me/…`, `github.com/…` и адреса кнопок «поделиться» для X и ВКонтакте.
В разметке за это отвечают атрибуты `data-cfg`, `data-contact` и `data-share` — их трогать не нужно.

## Запуск локально

Достаточно открыть `index.html` двойным кликом. Если хочется нормального локального сервера:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Публикация на GitHub Pages

1. Создайте репозиторий. Если назвать его `<ваш-логин>.github.io`, сайт будет на корневом домене; иначе адрес будет вида `<логин>.github.io/<репозиторий>/`.
2. Залейте файлы:

   ```bash
   git init
   git add .
   git commit -m "Портфолио"
   git branch -M main
   git remote add origin https://github.com/<логин>/<репозиторий>.git
   git push -u origin main
   ```

3. В настройках репозитория: **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Первый деплой запустится сам после пуша. Дальше — при каждом push в `main`.

Если автодеплой не нужен, удалите папку `.github` и в **Settings → Pages** выберите **Deploy from a branch → main → / (root)**.

## Что нужно заменить

Все личные данные сейчас — правдоподобные заглушки. Найдите и поправьте:

| Где | Что менять |
| --- | --- |
| `config.js` | имя, город, почта, Telegram, GitHub, ссылка для «поделиться» |
| `index.html`, мета-теги | описание для превью в соцсетях |
| секция `.hero` | курс и текст о себе |
| секция `#projects` | четыре карточки: названия, описания, стек, ссылки `github.com/username/...` |
| секция `#skills` | списки технологий |
| секция `#exp` | таймлайн: даты, места, роли |
| секции `#now`, `#faq` | что изучаете и ответы на частые вопросы |
| ссылки на `cv.pdf` | положите рядом файл резюме или уберите обе ссылки (в герое и в контактах) |

Учебный план в секции `#edu` заполнен по реальному плану 2026 года: 02.03.02, ИКБ, кафедра информатики, 190 з.е. дисциплин + 41 практики + 9 на ВКР. Распределение предметов по курсам выведено из номеров семестров — сверьте со своим планом, если он отличается.

## Темы

Тема хранится в `localStorage` под ключом `theme`. Пока пользователь не нажал кнопку, сайт следует системной настройке `prefers-color-scheme` и реагирует на её смену на лету. Чтобы не было вспышки светлого фона при загрузке, тема выставляется маленьким скриптом в `<head>` до отрисовки.

Цвета живут в CSS-переменных в начале `styles.css`: блок `:root` — светлая тема, `[data-theme="dark"]` — тёмная. Поменяете два акцента `--acc` и `--acc2` — перекрасится весь сайт, включая анимированную сферу.

## Адаптив

Разметка резиновая от 320 px. Ключевые точки: 640 px (цифры в четыре колонки, таймлайн в две), 960 px (герой и образование в две колонки, проекты в две, навыки в четыре). Меню сворачивается в кнопку до 960 px. Размеры шрифтов заданы через `clamp()`, так что промежуточные ширины тоже выглядят прилично.

## Доступность

Ссылка «Перейти к содержимому» для клавиатуры, видимый фокус, вкладки плана с ролями `tablist`/`tab`/`tabpanel` и управлением стрелками, цели нажатия не меньше 44 px, контраст текста проверен в обеих темах.

Все анимации выключаются при системной настройке «уменьшить движение»: текст в терминале и блоки показываются сразу.

Без JavaScript сайт остаётся читаемым: показываются все секции и все четыре курса учебного плана, не работает только переключение темы и мобильное меню.
